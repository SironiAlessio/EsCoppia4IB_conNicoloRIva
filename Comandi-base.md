git init : per inizializzare la cartella git 
git status : mostra lo stato (se è stato modificato o no il file)
git add . : aggiunge le modifiche
git commit -m “messaggio” : Fa un commit con un titolo
git switch bugfix : cambia nel branch 'bugfix'
git branch : mostra in che branch siamo
